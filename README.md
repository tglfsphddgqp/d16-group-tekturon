## Overview

D16 Group Tekturon is a unique 16-tap delay where each tap is controlled by a step sequencer, enabling complex rhythmic delay patterns that evolve and groove in sync with the music.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **D16 Group Tekturon** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **16 Taps** | Sixteen individually controllable delay taps with sequencer gating |
| **Step Sequencer** | Per-tap gate, level, and pan in a 16-step pattern |
| **Tempo Sync** | All tap times locked to BPM with subdivision selector |
| **Feedback Matrix** | Cross-feedback between taps for complex regenerating echo patterns |
